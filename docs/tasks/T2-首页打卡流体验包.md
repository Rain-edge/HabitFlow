# T2 首页打卡流体验包

- 状态：待实现（依赖 T1 已集成：需要 `TodayItem.skipped_today`、`HabitRecord.is_skipped`、`/records?habit_id=&limit=` 查询）
- 目标：在 Dashboard / RecordDialog 上落地 6 个体验优化点，覆盖三个方向——补实用小功能（庆祝时刻、昨日遗漏提醒、每日激励语）、交互顺手度（重排动画、长按菜单、快速输入防丢预填）、跳过保护的 UI 入口与展示（R-A 的 UI 半边）。

- 接口合同（对外提供/依赖）：
  - **依赖 T1 冻结形态**（不得自行改动 T1 文件来适配）：`TodayItem.skipped_today`、`TodayItem.record.is_skipped`、创建跳过 `api.post("/records", { habit_id, record_date, is_skipped: true })`、取消跳过 `api.delete("/records/{id}")`、`api.get("/records?habit_id=X&limit=N")`、`api.get("/records?on_date=…")` 含 `is_skipped`
  - 本卡不新增跨页面公共接口；新增组件只被 Dashboard 消费
  - 发现需要改数据层/其他页面 → 记入「发现的问题」交主控，不擅自改

- 功能点清单（每个功能点独立约定式提交）：
  1. **R-A UI**：跳过入口在长按菜单「跳过今天」；已跳过卡片显示徽章（badge 样式，与「补签」徽章风格一致），点击徽章或菜单「取消跳过」可恢复；跳过卡片不可一键打卡
  2. **R-F 长按快捷菜单**：长按今日习惯卡片弹出菜单——查看详情 / 编辑习惯 / 跳过今天（或取消跳过）/ 补签到昨天（尊重 `allow_backfill`，仅昨日未完成时可用）；需提供视觉按压反馈，桌面端兼容右键或长按 500ms
  3. **R-G 快速输入防丢+预填**：快速输入框失焦改为自动保存（非空时）；打开时预填该习惯上一次数值（经 T1 的 `?habit_id=&limit=1`）
  4. **R-E 列表重排动画**：打卡完成后卡片在「未完成→已完成」重排时用 FLIP 平滑位移（复用现有 `ease-soft` 曲线），不得引重依赖库
  5. **R-B 庆祝时刻**：当日全部完成时全屏彩带庆祝（Canvas 轻实现或 CSS 方案，自研不引库）+ 完成文案；同一自然日只触发一次（本地记忆已庆祝日期）
  6. **R-C 昨日遗漏提醒**：首页顶部提醒条「昨天还有 N 项未完成」，展开列出昨日未完成习惯（排除已跳过、排除 `allow_backfill=false`），点击直接弹出昨日日期的 RecordDialog
  7. **R-D 每日激励语**：hero 卡片内置语料库（≥30 条）按日期哈希轮换，风格与「记录坚持」主线一致
- 涉及文件：
  - 修改：`frontend/src/pages/Dashboard.tsx`、`frontend/src/components/RecordDialog.tsx`、样式文件（动画 keyframes 按需）
  - 新建：长按菜单 / 庆祝 / 激励语组件（放 `frontend/src/components/`，命名执行时定）
  - 禁止触碰：`frontend/src/local/`（数据层归 T1）、其他页面（Statistics/Calendar/Journal/Settings/HabitDetail）
- 验收标准（浏览器走查，浅色+暗色各过一遍）：
  1. 长按卡片弹菜单，四个入口全部可用；跳过 → 卡片徽章出现、连续天数桥接不中断（用相邻两天数据验证）、完成率分母排除该项
  2. 快速输入：输入中失焦自动保存不丢值；预填显示上一次数值
  3. 打卡后卡片平滑换位，无闪跳；连续快速点击不误触
  4. 全部完成触发一次彩带，刷新同日不重复触发
  5. 昨日有未完成项时提醒条出现且可补签；昨日全部完成/跳过时提醒条不出现
  6. hero 激励语当日固定、次日变化
  7. `tsc --noEmit` 与 `vite build` 通过
